*System startup
 the subservices were disabled internally,
 to enable them, you need to enter the command
 -disable_subservice=false in the start.sh file
 or, if using a start.bat file, in the start.bat file.
 
*Cluster services
 Disabled IoT related APIs and scanner internally,
 to enable them, you need to enter the command
 -allow_iot=true in the start.sh file
 or, if using a start.bat file, in the start.bat file.

*hardware or interfaces
 the subservices Skip mdadm reload config
 during startup, might result in werid RAID device
 ID in some Linux distro disabled internally,
 to enable them, you need to enter the command
 -skip_mdadm_reload=true in the start.sh file
 or, if using a start.bat file, in the start.bat file.
